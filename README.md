# Red Elohim — Casas de Paz

Landing mobile-first para Red Elohim, Villa Hermosa, Guatemala.

## Ejecutar

npm install
npm run dev

## Datos

Edita `data/casasDePaz.ts` para cambiar nombres, Maps, WhatsApp, coordenadas, horario y fotografías.

## Fotos

Añade `public/photos/casa-01.webp`, `casa-02.webp` y `casa-03.webp` con fotografías reales antes de publicar.

## Producción

- Cambia el dominio real en metadata si deseas Open Graph absoluto.
- Sirve la página por HTTPS para geolocalización.
- Prueba los enlaces de WhatsApp, Maps y permiso de ubicación en iPhone y Android.
- Usa `/casas-de-paz` como destino del QR.
